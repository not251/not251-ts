Info

This code analyzes a MIDI note’s placement in chord, scale, and chromatic contexts using a modulo value (typically 12) and applies a set of modifications, paired with their context, generating a melody. The modifications can be custom or can follow one of these ornament generation algorithms:

Run: Computes a melodic run by calculating a starting value so that, when stepped (by ±1) for the given length, the final value reaches the specified degree. Use ascending (true) or descending (false) to set the run’s direction.

Run2: Produces a simple sequence from the provided start value to the end value (inclusive). The sequence is ascending if start is less than end, and descending otherwise.

Diminution: Generates a sequence where the first and last elements equal the given degree. The intermediate values form a melodic line that increases or decreases (as specified by up), and the left flag controls its sorting order.
